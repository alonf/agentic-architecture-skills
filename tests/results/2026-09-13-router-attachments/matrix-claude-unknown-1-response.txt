**3. Responsibilities** (three, not atomic)
1. Collect evidence about the failed run.
2. Analyse the evidence to identify a likely cause.
3. Deliver the report to the requester.

**4. Routing decisions**
- **R1 Collect evidence: deterministic code, provisionally.** Fetching a known set of artefacts from known locations is a fixed procedure. It cannot be finalised because the sources are unknown. It moves into an agent's read loop only if the challenge on R2 resolves to "no".
- **R2 Analyse: bounded AI capability, provisionally.** Deterministic rules come first in routing order and would suffice if failure signatures are enumerable. That is unknown, so rules cannot be confirmed sufficient. A single model call with a fixed input (the evidence bundle) and a fixed output (likely cause, supporting references, confidence, unresolved questions, or "cause not established") is the next rung, and nothing stated rules it out. A single agent is not permitted because the challenge has not returned "no".
- **R3 Deliver: deterministic code.** Rendering the fixed output and sending it over the requester's channel involves no decision.

Workflow axis: a fixed sequence of collect, then analyse, then deliver. Three fixed steps do not justify a workflow engine. Revisit only if collection spans several sources with retries.

**12. Decisions, evidence, trade-offs, assumptions, open questions**
Decision: not an agent on the stated facts. Deterministic collect, bounded analyse, deterministic deliver. Trade-off: a bounded call is cheaper and more predictable, but it returns "cause not established" whenever the fixed bundle is insufficient, whereas an agent would read further at higher cost and with an unresolved stopping policy. Assumptions: none beyond those labelled hypothesis. Open questions, the first one decisive:
1. Can all relevant evidence be assembled into a fixed bundle before analysis, or does what to read next depend on what was already read?
2. What are the evidence sources and formats, and who grants read access?
3. Are failure causes an enumerable set with recognisable signatures?
4. Where does the report go, and does delivery have side effects?

## Runtime and control (step 3)

- **Hosting placement is open.** The decision does not say whether this agent runs in-process or in a hosted runtime. The peer is hosted elsewhere by definition. This choice sets isolation and session lifecycle, so it must be resolved before the row 2 design is final.
- **Binding is a gate, not a detail.** A2A layers on the peer's ingress. Wire-binding compatibility between two peers is recorded as unverified. Agent-card discovery must run as a mandatory step before any delegation, and the design must fail closed on a binding or version mismatch.
- **Session lifecycle belongs to the host.** The agent session must not be assumed to outlive the hosting layer's idle and reclaim policy.
- **Delegation carries a task, not a credential.** If the peer must act as the calling user, that needs an explicit delegated-access consent step. A propagated identifier does not grant it.
- **No human-authority layer is invoked.** None of the four responsibilities asks for sign-off. If one emerges, name which of the three layers applies: workflow gate, per-call approval, or consent.

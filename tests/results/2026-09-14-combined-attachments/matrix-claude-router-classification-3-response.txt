**3. Responsibilities.** The requirement is atomic: classify one supplied text into a closed output schema. Validating the returned label against the supplied set is part of the same mechanism's output contract, not a second responsibility.

**4. Routing decisions.**
- **Deterministic code alone:** rejected as the sole mechanism. Without a rule table, keyword or pattern rules cannot make the semantic judgment. Deterministic code is retained for the output contract. It checks the returned label against the supplied set and coerces anything else to unknown.
- **Bounded AI capability:** selected. One call takes the text and the category definitions and returns one label from the closed set or unknown.
- **Single agent:** not needed. See the challenge record.
- **Multi-agent:** not needed.
- **Workflow axis:** none. The sequence is fixed: call, validate, return. Batch use is a plain loop with ordinary transport retry, not an orchestration engine.

- **Workflow-only:** cannot supply the missing semantic classification on its own, though a trivial fixed sequence can wrap the bounded call.

**12. Decisions, evidence, trade-offs, assumptions, open questions.**
- **Decision:** bounded AI capability with deterministic output validation. No agent, no workflow engine, no MCP surface, no consequential action.
- **Evidence relied on:** the requirement text at rung 4 and the skill's counter-example at rung 3. Nothing else was observed.
- **Trade-off accepted:** a model call is non-deterministic and can misclassify. The closed label set, the unknown fallback, and a labelled evaluation set bound that risk. Nothing an agent would add is given up, because there is no second step for an agent to choose.
- **Assumptions, labelled:** single-label output. The definitions discriminate well enough to be usable. Text and definitions fit one call's input.
- **Open questions:** whether a confidence floor should force unknown. Whether multi-label is ever wanted. Whether a labelled evaluation set exists. What language mix arrives. Who consumes the label and whether that consumer performs any consequential action.
